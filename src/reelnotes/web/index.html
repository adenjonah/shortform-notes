reelnotes

How do you want to run the AI?

reelnotes turns an Instagram Reel, TikTok or YouTube Short into a Markdown note: caption, transcript, and the key takeaways. One model call per reel writes the summary. Pick where that call runs.

Saved to your local config file only (never sent anywhere but api.openai.com). Get one at platform.openai.com → API keys.
Saved to your local config file only. Get one at console.anthropic.com → API keys.

How should the audio be transcribed?

The transcript is what makes spoken-only reels useful. It's optional; caption-only notes still work.

Transcription runs on OpenAI's audio model. Saved locally only.

Where should notes go?

One .md file per reel, named <date>-<creator>-<title>.md. Any folder works; if you use Obsidian, paste a folder inside your vault.
